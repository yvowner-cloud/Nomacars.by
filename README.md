# Nomacars.by

Сайт пригона авто с аукционов США (Copart, IAAI) в Беларусь и Россию: еженедельная ИИ-подборка лотов, калькулятор под ключ, кабинеты клиента и владельца.

Полное ТЗ — [`SPEC.md`](SPEC.md). Сборка идёт по этапам из раздела 14.

## Статус

- [x] **Этап 1** — дизайн, главная, каталог (фильтры, плитка/таблица), карточка лота (галерея, отсчёт до торгов, разбор ИИ, расчёт под ключ), калькулятор, прошедшие торги, SEO (метаданные, sitemap, robots, schema.org). Данные — демо-лоты из `src/lib/lots.ts`, вход — демо (код 1234).
- [ ] Этап 2 — вход по SMS (Supabase Auth), роли
- [ ] Этап 3 — тарифы в базе + кабинет владельца «Тарифы»
- [ ] Этап 4 — заявки, Telegram-уведомления, CRM
- [ ] Этап 5 — кабинет клиента: этапы, счета, документы
- [ ] Этап 6 — API аукционов + ИИ-подборка (шлюз https://api.aiai.by/v1)
- [ ] Этап 7 — рыночные цены (av.by, auto.ru, drom.ru) + цены выкупа
- [ ] Этап 8 — аналитика, полировка

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # тесты калькулятора
npm run build
```

## Где что лежит

- `src/lib/calc.ts` — калькулятор под ключ (покрыт тестами `calc.test.ts`)
- `src/lib/tariffs.ts` — стартовые тарифы (**демо-значения, сверить перед запуском**)
- `src/lib/lots.ts` — демо-лоты; `src/lib/ai.ts` — демо-разбор ИИ
- `src/lib/company.ts` — контакты компании (заглушки)
- `src/app/*` — страницы, `src/components/*` — компоненты
