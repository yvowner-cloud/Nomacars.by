# Ncars.by (бывш. Nomacars)

Сайт пригона авто с аукционов США (Copart, IAAI) в Беларусь и Россию. Язык интерфейса — только русский.

**Начало новой сессии: прочитай `_plans/handoff.md`** — там решения владельца, что сделано, следующие шаги и известные мины. ТЗ — `SPEC.md` (разделы про Supabase/Vercel устарели: хостинг — свой сервер hoster.by + PostgreSQL, см. handoff).

## Правила
- Владелец — не программист: технические решения принимаешь сам, спрашиваешь только о продукте, деньгах, сервисах, внешнем виде; вопросы с вариантами и рекомендацией.
- На публичном сайте не писать «ИИ»: «Оценка Ncars», «Разбор Ncars», «Подборка Ncars».
- Дизайн — в стиле NPA (токены в `src/app/globals.css`), без логотипов/текстов NPA.
- Ставки таможни/доставки в `src/lib/tariffs.ts` — демо-значения, не выдавать за реальные.
- Секреты — только в `/srv/nomacars/.env` на сервере и GitHub Secrets; не просить ключи/пароли в чате.

## Команды
- `npm run dev` · `npm test` (калькулятор) · `npm run build`
- Выкладка: push в `main` → GitHub Actions `deploy.yml` → сервер (см. `deploy/README.md`).
