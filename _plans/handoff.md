# Nomacars.by — состояние проекта и итоги обсуждения (сессия 14.11.2026)

Этот файл — полный контекст для следующей сессии. Читать вместе с `SPEC.md` (ТЗ) и `CLAUDE.md`.

## Задача
Сайт компании, которая пригоняет авто с аукционов США (Copart, IAAI) в **Беларусь и Россию**. Язык — только русский.
Ядро: еженедельная автоматическая подборка лотов + калькулятор «под ключ» + кабинет клиента + кабинет владельца (CRM).
Бренд: **Nomacars**, домен **nomacars.by**. Репозиторий: https://github.com/yvowner-cloud/Nomacars.by (ветка `main`).

## Решения владельца (из «допроса», с формулировками)
- Страны: **РФ и РБ**, переключатель в калькуляторе, итог в $ и ₽/BYN.
- Сборка сайта — **в Claude (Claude Code)**.
- Каталог — **только подборка** (не вся лента аукциона): **300 лотов раз в неделю**, публикуются **автоматически**; у каждого лота **тумблер «показывать на сайте»** в кабинете владельца.
- Критерии отбора: **только «проходные» 3–5 лет** (считать на дату растаможки), **минимальные повреждения**, **лучшая цена относительно рынка** (РБ — av.by, РФ — auto.ru/drom.ru). Сравнение с рынком — **только для отбора, на сайте не показывать**. Дата торгов не важна, важно наполнить сайт.
- Фото и описания — с аукциона. У владельца **есть дилерский аккаунт** на аукционах → решено брать данные через **отдельный платный сервис данных** (~$100–300/мес), аккаунт не трогать (риск блокировки).
- Проданные лоты остаются на сайте с **реальной ценой выкупа**; система сама отслеживает итог торгов.
- **Цены видны только после регистрации** (вход по SMS-коду), фото/описания открыты всем (SEO).
- Калькулятор подробный, **«Услуги компании» — фиксированная сумма отдельной строкой** (в демо $700).
- Кабинет клиента: этапы доставки, **счета без онлайн-оплаты** (оплата переводом, «оплачено» отмечает менеджер), документы PDF, избранное.
- Кабинет владельца: пока работает **один владелец**, менеджеров добавлять позже; **тарифы меняет только владелец**.
- Заявка «Хочу эту машину» → в кабинет + уведомление в Telegram. **Депозит не обязателен.**
- ИИ: шлюз **https://api.aiai.by/v1** (OpenAI-совместимый, проверить формат/модель/цену у сервиса), топовая модель с анализом фото, ключ только на сервере (`AIAI_API_KEY`).
- **На сайте не писать «ИИ»**: «Оценка Nomacars», «Разбор Nomacars», «Подборка Nomacars». В кабинете владельца «ИИ-подборка» можно.
- Дизайн — **в стиле NPA (npauctions.com)**: цвета и стилистика по скриншотам владельца (чёрная верхняя полоса с логотипом справа, серое меню с узкими заглавными пунктами Oswald, мега-меню «Купить» с красной полосой и стрелками ›, слайдер с красной плашкой, плитки категорий, серая полоса со слоганом, «Глобальный поиск» слева и строки лотов, чёрный подвал в 4 колонки). Логотип/тексты NPA не копировать.
- Хостинг — **свой облачный сервер hoster.by** (вместо Vercel/Supabase). Домен тоже на hoster.by. Рекомендованная конфигурация: **2 vCPU, 4 ГБ RAM, NVMe 60 ГБ, 1 публичный IP, Ubuntu 24.04**, включить бэкапы. На момент окончания сессии владелец **покупает сервер**.

## Что сделано
- `SPEC.md` — полное ТЗ (промт). ⚠ В нём ещё упоминаются Supabase/Vercel — **устарело**, стек теперь: свой сервер, PostgreSQL, свой вход по SMS (см. ниже).
- **Этап 1 готов** (Next.js 15, TypeScript, CSS-токены в `src/app/globals.css`):
  - главная (слайдер, плитки, слоган, ближайшие торги, топ недели, как купить, цены выкупа, FAQ), мега-меню, каталог «Глобальный поиск» (фильтры, пагинация, список/плитка), карточка лота (галерея, отсчёт до торгов, расчёт под ключ РБ/РФ, разбор, характеристики, похожие), калькулятор с проверкой «проходной», прошедшие торги, SEO (metadata, sitemap, robots, schema.org Car).
  - данные — демо-лоты `src/lib/lots.ts`, демо-разбор `src/lib/ai.ts`, вход — демо (код 1234, localStorage) в `src/components/Providers.tsx`.
  - тесты калькулятора `src/lib/calc.test.ts` (8 шт., проходят).
- **Размещение**: `deploy/setup-server.sh` (ставит Node 22, PostgreSQL, Nginx, Certbot, swap, ufw, пользователя `deploy`, БД, `.env`, systemd-службу `nomacars`, печатает 4 секрета), `.github/workflows/deploy.yml` (push в main → тесты → сборка standalone → rsync на сервер → рестарт; без секретов просто пропускает выкладку), `deploy/README.md` — инструкция. `next.config.ts` → `output: "standalone"`.
- `demo/index.html` — весь сайт одним файлом (интерактивный макет, включая кабинеты клиента/владельца) для показа.
- Скриншоты сайта отправлялись владельцу.

## Следующие шаги
1. **Владелец**: купить сервер → A-записи `nomacars.by` и `www` на IP → в консоли сервера выполнить
   `curl -fsSL https://raw.githubusercontent.com/yvowner-cloud/Nomacars.by/main/deploy/setup-server.sh | bash`
   → добавить 4 секрета (`DEPLOY_HOST`, `DEPLOY_PORT`, `DEPLOY_KNOWN_HOSTS`, `DEPLOY_SSH_KEY`) в GitHub → Actions → «Deploy to server» → Run workflow. Скрипт на реальном сервере ещё **не запускался** — первый прогон проверить по выводу/скриншоту.
2. **Этап 2 — вход по SMS и роли** на своём сервере: PostgreSQL (миграции), сессии (cookie, `SESSION_SECRET`), SMS-провайдер РБ (сравнить SMS-assistent / Rocket SMS / МТС Коммуникатор — цена ~0,05–0,10 BYN за SMS по РБ, РФ дороже; выбор за владельцем), лимиты отправки кода, роли client/manager/owner. Цены отдавать сервером только авторизованным.
3. Этапы 3–8 по `SPEC.md` раздел 14 (тарифы в БД + кабинет владельца, заявки + Telegram, кабинет клиента, API аукционов + еженедельная подборка, рыночные цены + цены выкупа, аналитика/полировка). Фото лотов хранить на диске сервера (`UPLOADS_DIR`).
4. Заменить заглушки: контакты в `src/lib/company.ts`, ставки в `src/lib/tariffs.ts` (**демо-значения, сверить с таможней РБ/РФ**), ссылки соцсетей, реальные фото для слайдера/плиток.
