# Поставщики данных Copart/IAAI для этапа 6 — сравнение (15.11.2026)

Официального открытого API у Copart и IAAI нет — все варианты ниже это сторонние сервисы-агрегаторы. Цены и условия собраны из поиска/страниц поставщиков и **требуют проверки на их сайтах** (из облачной среды Claude сайты поставщиков напрямую не открывались).

## Что нужно сайту (объём)
- Еженедельно просмотреть все активные лоты нужных годов (тысячи) → нужен **массовый доступ (каталог/фид или поиск с фильтрами)**, а не только поиск по одному VIN.
- Детали + **HD-фото** ~500–700 кандидатов в неделю; фото копируем к себе (у многих поставщиков ссылки на фото живут ~сутки).
- Ежедневная проверка статуса ~300 опубликованных лотов и **цены выкупа** после торгов.
- Поля: повреждения (основное/второе), тип документа (title), Run & Drive, пробег, двигатель, топливо, площадка/штат, дата торгов, текущая ставка.
- Оценка: **~10–20 тыс. запросов в месяц** или безлимитный фид.

## Рекомендация
Шорт-лист из трёх, взять у каждого пробный доступ и сравнить на наших реальных запросах:
1. **API Auctions — безлимит $150/мес** (если подтвердится): предсказуемая цена при ежедневных проверках.
2. **AuctionsAPI** — фид + архив с финальными ставками, обновление раз в час: лучше всего подходит под «каталог + цены выкупа».
3. **ApiCar Pro $149 (50 000 запросов)** — запас по запросам, есть бесплатный тариф для проверки.

## Вопросы поставщику перед оплатой
1. Есть ли массовая выгрузка/фид всех активных лотов Copart и IAAI с фильтром по году и обновлением минимум раз в сутки?
2. Какие поля: основное/второе повреждение, title, Run & Drive, пробег, двигатель, топливо, штат/площадка, дата торгов, текущая ставка, Buy Now?
3. Сколько фото на лот, разрешение, сколько живут ссылки, можно ли хранить копии у себя?
4. Даёте ли финальную цену продажи и как быстро после торгов? Что, если продавец не раскрыл цену?
5. Лимиты запросов, что при превышении, есть ли вебхуки об изменении статуса лота?
6. Можно ли оплачивать из Беларуси (карта, крипта USDT, счёт на юрлицо)? Есть ли договор/акт?
7. Условия использования: можно ли показывать данные и фото на публичном сайте?
