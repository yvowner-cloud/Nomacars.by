# Демо-версия сайта одним файлом

`index.html` — интерактивный макет всего сайта Nomacars в одном файле: главная, меню «Купить», каталог с глобальным поиском, карточка лота, калькулятор, кабинет клиента и кабинет владельца (заявки, счета, тумблеры лотов, тарифы).

Открывается двойным щелчком в любом браузере, сервер не нужен. Вверху переключатель «Смотреть как: Гость / Клиент / Владелец», код входа по SMS в демо — 1234. Все данные примерные и хранятся только в браузере («Сбросить демо» возвращает исходное состояние).

Рабочий сайт — Next.js-приложение в корне репозитория.
