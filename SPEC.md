## РОЛЬ И ЗАДАЧА

Ты — senior full-stack разработчик и продуктовый дизайнер. Собери полноценный рабочий веб-сайт компании, которая пригоняет автомобили с аукционов США (Copart, IAAI) в **Россию и Беларусь**.

Сайт — это не просто лендинг. Это:
1. **Публичный каталог** из автомобилей, которые раз в неделю автоматически отбирает ИИ из лотов аукционов.
2. **Калькулятор стоимости «под ключ»** для России и Беларуси.
3. **Личный кабинет клиента** (регистрация по телефону, избранное, статус машины, счета, документы).
4. **Кабинет владельца/менеджера** (CRM по заявкам, управление каталогом, тарифами, ИИ-подборкой).

Язык интерфейса — **только русский**. Сайт верстается **mobile-first** (большинство клиентов — со смартфона), полностью адаптивен.

Стек: Next.js (App Router) + TypeScript + CSS с дизайн-токенами (src/app/globals.css, аукционный стиль: чёрная служебная полоса, белая шапка с поиском, красное меню, узкие заглавные заголовки Oswald); база, вход, файлы и фоновые задачи — Supabase (Postgres, Auth, Storage, Edge Functions, cron); хостинг сайта — Vercel. Код хранится в GitHub-репозитории, каждый этап — отдельный коммит. Страницы лотов рендерятся на сервере (SSR/ISR) для SEO. Все секреты (ключи API) — только в переменных окружения сервера / Supabase Secrets, никогда во фронтенде. Перед завершением каждого этапа: `npm run build` без ошибок, базовые тесты калькулятора (unit) и проверка ключевых страниц в браузере.

## 2. ДИЗАЙН

Стиль — **профессиональная аукционная площадка** (в духе крупных американских автоаукционов, но без копирования чужих логотипов, названий и фирменного стиля):

- бейджи статусов («Топ недели», «Торги скоро», «Продан за $X», «Торги завершены»);
- фильтры слева на десктопе, выезжающая панель на мобильном;
- галерея фото лота с увеличением и свайпом.

## 3. РОЛИ ПОЛЬЗОВАТЕЛЕЙ

| Роль | Что может |
|---|---|
| **Гость** | Видит главную, каталог, карточки лотов (фото, характеристики, повреждения, описание ИИ). **Не видит цены** — вместо них блок «Зарегистрируйтесь, чтобы увидеть цену под ключ». |
| **Клиент** (зарегистрирован) | Видит цены и калькулятор, цены выкупа проданных лотов, добавляет в избранное, оставляет заявку «Хочу эту машину», видит свой кабинет. |

| **Владелец** | Всё, что менеджер, плюс: тарифы, комиссия, ставки таможни, курсы, настройки ИИ-подборки, управление менеджерами, настройки компании. |

Доступ разграничить через Supabase RLS.

## 4. РЕГИСТРАЦИЯ И ВХОД

- Вход/регистрация **по номеру телефона с кодом из SMS** (коды РФ +7 и РБ +375).
- SMS-провайдер вынести в отдельный модуль/Edge Function, чтобы его можно было заменить (ключ в Secrets).
- При регистрации: имя, телефон, страна (Россия / Беларусь) — страна становится значением по умолчанию в калькуляторе.
- Защита: лимит запросов кода (не чаще 1 раза в 60 сек, не более 5 в час на номер), капча при подозрительной активности.
- После регистрации пользователь возвращается на ту же страницу, где был, и сразу видит цену.

## 6. ИИ-ПОДБОРКА (ядро сайта)

ИИ подключается через шлюз **`https://api.aiai.by/v1`** (OpenAI-совместимый формат: `POST /v1/chat/completions`, ключ — в Supabase Secrets как `AIAI_API_KEY`, передаётся в заголовке `Authorization: Bearer`). Базовый URL, ключ и ID модели хранятся в настройках/секретах, чтобы их можно было сменить без правки кода. Используется самая мощная доступная в шлюзе модель с поддержкой изображений: она анализирует и текст, и **фото повреждений**. Все запросы к ИИ идут только с сервера (Edge Function), никогда из браузера.

### 6.1. Еженедельный цикл (cron, раз в неделю, день/время настраиваются)
1. Забрать из API свежие лоты.
2. **Жёсткий фильтр (без ИИ, дёшево):**
   - возраст авто **от 3 до 5 лет на ожидаемую дату растаможки** = дата торгов + срок доставки (по умолчанию 75 дней, настраивается). Машина, которая станет старше 5 лет к моменту таможни, — исключается;
   - исключить: flood/утопленники, fire/пожар, проблемы с документами (title не допускающий регистрацию), «не на ходу» (non-run), разбор на запчасти, биохазард;
   - исключить лоты с уже прошедшими торгами.
3. **Оценка ИИ** оставшихся кандидатов:
   - степень повреждений по фото и описанию → оценка 1–10 и **примерная стоимость ремонта** ($ от–до);
   - расчёт итоговой цены «под ключ» калькулятором (раздел 7) для РБ и для РФ;
   - **сравнение с рынком** (только внутреннее, на сайте не показывается): для РБ — объявления av.by, для РФ — auto.ru / drom.ru по той же марке/модели/году/двигателю → медиана рыночной цены → экономия;
   - общий балл = минимальные повреждения + максимальная экономия относительно рынка.
4. Отобрать **300 лучших** и **автоматически опубликовать** в каталог.
5. Для каждого опубликованного лота ИИ пишет:
   - короткое продающее описание (3–5 предложений, без воды и без обещаний, которых нельзя гарантировать);
   - блок «Повреждения простыми словами» — что повреждено и что это значит для ремонта;
   - блок «Почему стоит взять» (2–3 пункта);
   - «Риски» (честно, 1–3 пункта).
6. Пометить 10–20 лучших значком **«Топ недели»**.

### 6.2. Сбор рыночных цен (av.by, auto.ru, drom.ru)
- Отдельный модуль сбора рыночных цен с кешированием на 7 дней; бережные запросы (паузы, лимиты).
- Если площадка недоступна / блокирует — **подборка не останавливается**: лот оценивается без рыночного сравнения, а в кабинете владельца стоит пометка «Нет рыночного сравнения».

### 6.3. Отслеживание опубликованных лотов
- Ежедневно проверять статус каждого опубликованного лота через API.
- После торгов записать **реальную цену выкупа** → лот остаётся в каталоге с бейджем **«Продан за $X»** (цена видна только зарегистрированным).
- Если цену получить не удалось → бейдж «Торги завершены», никаких выдуманных цифр.
- Проданные лоты автоматически переезжают в раздел «Прошедшие торги / реальные цены» и в каталоге по умолчанию показываются после актуальных.

### 6.4. Управление в кабинете владельца
- Список всех опубликованных лотов с **тумблером «Показывать на сайте»** у каждого (по умолчанию включён) — мгновенно снимает/возвращает лот.
- Видны внутренние данные: балл ИИ, оценка ремонта, рыночная медиана и экономия для РБ/РФ, пометки об ошибках.
- Кнопки: «Запустить подборку сейчас», «Пересчитать цены», лог последнего запуска (сколько лотов получено / отфильтровано / опубликовано, ошибки, расход на ИИ).
- Настройки: количество лотов в неделю (300), день запуска, диапазон возраста (3–5), срок доставки, список исключаемых типов повреждений, ID модели ИИ.

## 7. КАЛЬКУЛЯТОР «ПОД КЛЮЧ»

Используется: (а) автоматически в каждой карточке лота, (б) на отдельной странице «Калькулятор», где клиент вводит данные сам.

**Ввод:** страна (переключатель **Россия / Беларусь**, по умолчанию — страна из профиля, запоминается), цена лота $, год выпуска (дата), объём двигателя см³, тип топлива (бензин / дизель / гибрид / электро), мощность л.с. (нужна для РФ), аукцион (Copart / IAAI), штат/площадка нахождения.

**Вывод — подробная разбивка:**
1. Цена лота
2. Аукционный сбор (по таблице сборов аукциона в зависимости от цены)
3. Доставка по США до порта (по таблице штат/площадка → порт)
4. Морской фрахт до порта назначения (Клайпеда / др. — настраивается)
5. Доставка от порта до РБ / РФ
6. Таможенные платежи (пошлина, НДС/сборы; **для РФ — утилизационный сбор**) — по формуле выбранной страны
7. Брокер / СВХ / оформление
8. **«Услуги компании — $X»** (фиксированная сумма отдельной строкой)
9. **Итого под ключ** — в $ и в местной валюте (₽ или BYN)
10. Ориентировочный срок доставки для страны
11. Кнопка **«Получить точный расчёт»** / «Хочу эту машину» → заявка

**Важно:**
- **Все ставки, таблицы и формулы хранятся в базе и редактируются владельцем** в кабинете (ставки таможни и утильсбора меняются). Стартовые значения заполни актуальными на сегодня с пометкой «проверить» и датой обновления.
- Курсы валют (USD, EUR → RUB, BYN) обновляются ежедневно с ЦБ РФ и НБРБ; владелец может вручную переопределить курс.
- Под итогом мелким текстом: «Расчёт ориентировочный, точную сумму фиксирует менеджер».
- Для гостя в карточке вместо цифр — размытый блок и кнопка «Зарегистрироваться и увидеть цену».

## 9. ЗАЯВКА «ХОЧУ ЭТУ МАШИНУ»

1. Клиент (только зарегистрированный; гостя сначала ведём на регистрацию и возвращаем) нажимает «Хочу эту машину».
2. Можно добавить комментарий и желаемую максимальную ставку.
3. Создаётся заявка: клиент + лот + снимок расчёта калькулятора на момент заявки.
4. Клиент видит: «Заявка принята, менеджер свяжется с вами в течение 30 минут в рабочее время».
5. Владелец/менеджер получает **уведомление в кабинете и в Telegram** (бот, токен и chat_id в настройках).
6. Защита от дублей: повторная заявка на тот же лот тем же клиентом не создаёт новую, а показывает существующую.
7. Также есть общая форма «Подберите мне авто» (бюджет, пожелания) → заявка без лота.

Депозит перед торгами **не обязателен**.

## 10. ЛИЧНЫЙ КАБИНЕТ КЛИЕНТА

- **Мои заявки и машины** — статус-трекер по этапам:
  `Заявка → Торги → Куплена → В порту США → В море → В порту назначения → На таможне → Готова к выдаче → Выдана` (+ `Отказ / не выиграли`). Дата каждого этапа, комментарий менеджера, фото (например, из порта).
- **Избранное.**
- **Счета:** список счетов (PDF с реквизитами), сумма, назначение (лот, доставка, таможня, услуги), статус «Ожидает оплаты / Оплачено». График платежей: сколько всего, сколько оплачено, сколько осталось. **Онлайн-оплаты нет** — клиент платит переводом, «Оплачено» отмечает менеджер.
- **Документы:** договор (PDF — клиент скачивает и подписывает), инвойс аукциона, коносамент, фото, таможенные документы — загружаются менеджером по этапам.
- **Уведомления:** при смене статуса, новом счёте или документе — уведомление в кабинете (+ счётчик на иконке) и по SMS только на ключевых этапах (куплена, в порту назначения, готова к выдаче).
- Профиль: имя, телефон, страна.

## 11. КАБИНЕТ ВЛАДЕЛЬЦА / МЕНЕДЖЕРА

1. **Дашборд:** новые заявки, машины в пути по этапам, ожидающие оплаты счета, итоги последней ИИ-подборки.
2. **Заявки (CRM):** список/канбан по статусам `Новая → В работе → Торги → Куплена → Доставка → Выдана / Отказ`, фильтры, поиск по телефону/VIN, назначение ответственного менеджера (на будущее).
3. **Карточка клиента:** контакты, все заявки и лоты, расчёты, история статусов, комментарии (внутренние — не видны клиенту), документы, счета.
4. **Машины в работе:** смена этапа доставки (клиент видит сразу), загрузка документов и фото.
5. **Счета:** создать счёт из заявки (автоподстановка сумм из расчёта), сгенерировать PDF с реквизитами компании, отметить «Оплачено».
6. **Каталог и ИИ-подборка** — см. раздел 6.4 (тумблеры, внутренние данные, запуск, логи, настройки).
7. **Тарифы и калькулятор** (только владелец): сборы аукционов, доставка по США, фрахт, доставка до РБ/РФ, ставки таможни РБ, ставки таможни и утильсбора РФ, брокер/СВХ, «Услуги компании» (фикс. сумма), курсы валют и ручное переопределение. История изменений тарифов.
8. **Пользователи** (только владелец): добавить/отключить менеджера.

## 12. КРАЙНИЕ СЛУЧАИ

- Лот снят с аукциона до торгов → бейдж «Снят с торгов», скрыть из каталога, у клиентов с заявкой — уведомление менеджеру.
- Клиент не выиграл торги → статус «Не выиграли», менеджер может предложить похожие лоты.
- API аукционов недоступен → каталог работает на сохранённых данных, в кабинете — предупреждение, cron повторяет попытку.
- ИИ вернул ошибку/пустой ответ на лот → лот не публикуется, пишется в лог.
- Неделя дала меньше 300 подходящих лотов → публикуем столько, сколько прошло фильтр, без ослабления критериев.
- Курс не обновился → используется последний известный с датой, в кабинете предупреждение.
- Гость нажал «Хочу эту машину» → регистрация → возврат на лот → заявка.
- Пустые состояния: пустое избранное, нет заявок, нет документов — с понятным текстом и кнопкой действия.
- Все загрузки и запросы — со скелетонами загрузки и понятными сообщениями об ошибке на русском.
